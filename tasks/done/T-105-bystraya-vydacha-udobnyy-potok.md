# T-105 · Упростить поток быстрой выдачи

- **Создана:** 2026-10-24
- **Реализована:** 2026-10-25
- **Область:** Frontend

## Решения владельца

Оплату/залог перенести в модалку по образцу обычной выдачи. Автоматическая сумма равна аренде, ручное значение и ноль сохраняются. WhatsApp проверяется без отправки сообщения. На странице только клиент, возврат, состав и итог; видимые ошибки незаполненных строк. После уточнения от 2026-10-25 убрать кнопку подстановки всей суммы и отдельную карточку успеха. После успеха — обычное уведомление с номером визита и чистая форма быстрой выдачи для следующего клиента.

## Реализация

Общие карточки костюмов, блок финансов и кнопка используются обычной и быстрой выдачей. Сохранение неопределённой команды и точный повтор сохранены. После успешной команды очищается черновик, режим остаётся быстрым. Нет перезагрузки приложения с потерей состояния остальных экранов.
