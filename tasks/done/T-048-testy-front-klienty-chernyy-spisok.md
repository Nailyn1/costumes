- [x] Хуки: ключи кэша (`clientKeys`), инвалидация после create/update/delete/blacklist.

## Результат

Добавлены `pages/ClientsPage.test.tsx` (11 тестов, MSW с «живым» состоянием клиента), `features/clients-children/components/clients/clientSelector.test.tsx` (клиент из ЧС недоступен в `ClientSelector`, после снятия запрета — доступен) и расширен `hooks/useClients.test.tsx` (5 тестов: инвалидация `clientKeys.lists()/detail()` после create/update/delete/blacklist).
Покрыто: список и бейдж «В ЧС», поиск (<2 символов — запроса нет, пустой результат, открытие карточки), добавление в ЧС (тело `{ blacklistReason }`, список обновляется), снятие (DELETE, бейдж и причина пропадают), 404 при добавлении — один toast с сообщением бэкенда, редактирование клиента (PATCH, невалидное имя не отправляется), удаление только после подтверждения, «Отмена» ничего не шлёт.
Решение по вопросу из критериев: в UI причина ЧС «необязательна» — при пустой причине уходит `blacklistReason: ""`; нашли, что карточка закрывается до ответа сервера — [T-076](T-076-chs-zakryvaet-kartochku-srazu.md). Редактирование/удаление ребёнка в карточке клиента не покрыто (в критерии задачи не входило).
