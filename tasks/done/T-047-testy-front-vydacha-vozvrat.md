## Критерии готовности

- [x] Единый поиск: ввод < 2 символов не ходит в API; debounce; код / имя / костюм / `C-0128` / телефон — запрос уходит с `q`; пустая выдача.
- [x] Выдача: доплата по умолчанию = остаток (можно 0), тип залога `cash` требует сумму, `document`/`none` — нет; кнопка «Выдать костюмы» блокируется на время мутации (нет двойной отправки), toast «Костюмы выданы. Визит NNNN»; ошибка бэкенда не закрывает модалку.
- [x] Возврат: «Костюмы возвращены» активна только когда отмечены **все** костюмы; до нажатия ничего не уходит в API; payload `complete-return` (`depositReturned`, `notes`); чекбокс «Залог отдали».
- [x] Блок «залог не возвращён» (completed, `deposit.returned=false`, `type≠none`): клик → «Забрали ли залог?» → `mark-deposit-returned`.
- [x] Списки «К выдаче» / «К возврату» обновляются после мутации (инвалидация `["visits"]`).
- [x] Таблица ↔ карточки на мобильном не тестируем (вёрстка).
- [x] `pnpm test` зелёные, typecheck и lint без новых ошибок.

## Результат

Добавлены `pages/IssuePage.test.tsx` (16 тестов + 1 `it.todo`) и `pages/ReturnPage.test.tsx` (13 + 2 `it.todo`) — через MSW; в `test/setup.ts` добавлена заглушка `IntersectionObserver` (нужна `react-intersection-observer` в списках).
Выдача: список и пустое состояние, единый поиск (<2 символов — запроса нет, `q` уходит, «Ничего не найдено», выбор результата открывает карточку), доплата по умолчанию = остаток, 0 допустим, залог «Нал» требует сумму, «Док»/«Нет» — без `amount`, тело `POST /visits/:id/issue`, защита от двойной отправки, закрытие модалки и уход визита из списка после успеха, ошибка 400 не закрывает модалку, отмена визита только после подтверждения; один сценарий с эмуляцией мобильной ширины (карточка «Оформить» → модалка).
Возврат: отметки костюмов ничего не отправляют, кнопка «Костюмы возвращены» блокируется при снятой отметке, тело `complete-return` (`depositReturned`, `notes`), визит без залога, ошибка 400, откат выдачи только после подтверждения; вкладка «Забытые залоги»: подтверждение → `mark-deposit-returned` → список обновляется.
Расхождения с описанием (не чинились): все костюмы отмечены сразу — [T-073](T-073-vozvrat-chekboksy-otmecheny-srazu.md); «₽» вместо «₸» в `DepositCard` — [T-074](T-074-depozit-valyuta-rubl.md); текст тоста выдачи — [T-075](T-075-tekst-toasta-vydachi.md). Инвалидация: после выдачи/возврата визит удаляется из кэша списка через `setQueriesData` (а не `invalidateQueries(["visits"])`), проверено поведением — визит пропадает из списка.
