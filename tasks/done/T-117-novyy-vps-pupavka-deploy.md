# T-117 · Подготовить деплой на новый VPS pupavka.site

- **Приоритет:** high
- **Область:** Инфраструктура
- **Создана:** 2026-11-25
- **Выполнена:** 2026-11-25

## Контекст

Владелец переносит Costumes CRM на Ubuntu 24.04, 185.100.66.194, домен pupavka.site. Приложение — /var/www/costumes, сертификаты — /etc/nginx/ssl/pupavka.site. Серверные команды владелец выполняет самостоятельно.

## Критерии готовности

- [x] Nginx в frontend использует новый домен и read-only Origin CA с хоста.
- [x] PostgreSQL не публикует порт, Compose ждёт готовности инфраструктуры.
- [x] Деплой использует новый каталог, точный SHA и выполняет миграции до запуска новой версии.
- [x] Паспорт VPS, иерархия файлов, восстановление БД и первый запуск описаны в .agents/deployment.md.
- [x] Конфигурации проверены; ограничения окружения зафиксированы.

## План

Обновить Compose, nginx.conf, workflow и документацию. Отдельный инфраструктурный коммит. Не подключаться к VPS, не применять миграции production, не выполнять push/merge.

## Результат

Подготовлены Compose, Nginx и GitHub Actions для нового VPS. Nginx остаётся в frontend-контейнере, сертификаты подключаются с хоста read-only. Добавлены healthcheck PostgreSQL/Redis, профиль tools для Redis Insight, TZ=UTC backend, остановка деплоя при ошибке и миграции до обновления backend. CI/CD использует точный SHA, сериализацию запусков и явный COMPOSE_FILE. Сертификаты/дампы исключены из Git и Docker-контекста, worktree-каталоги исключены из Docker-контекста.

Проверено: production Compose config и утверждения об отсутствии опубликованных внутренних портов/read-only mount; YAML workflow и порядок миграций; nginx -t в одноразовом контейнере с временным сертификатом. Shared build, typecheck обоих приложений, frontend lint/build, pnpm test (421 backend + 236 frontend) и pnpm test:int (101) прошли. Integration выполнялись в изолированных временных контейнерах costumes_test:5433 / Redis:6380 (db 15), поскольку стандартные порты заняты другим проектом. Реальный backup не восстанавливался, production-миграции не запускались.

Общий backend lint обнаружил 5 ранее известных ошибок форматирования T-116; затронутые данной задачей конфиги их не добавляют. Фактические проверки DNS, сертификата владельца и запуск VPS выполняются владельцем отдельно по .agents/deployment.md. Push/merge не выполнялись.
