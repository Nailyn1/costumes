# T-082 · Находить телефон через 8 и +7

- **Приоритет:** medium
- **Область:** Баги домена
- **Создана:** 2026-10-18
- **Выполнена:** 2026-10-18

## Контекст

`ClientChildService.searchClients` ищет цифры запроса как подстроку сохранённого телефона. Запрос с `8` в начале не находит тот же казахстанский номер, сохранённый как `+7…`. См. `apps/backend/src/client-child/client-child.service.ts` и требование поиска по телефону в T-043.

## Критерии готовности

- [x] Поиск по `8…` находит эквивалентный сохранённый `+7…` номер.
- [x] Поиск по `+7…` и неполному номеру продолжает работать.
- [x] Добавлены unit- и интеграционный тесты.

## План

1. Расширить фильтры и оценку телефонного поиска эквивалентным вариантом цифр `7` для запроса с ведущей `8`.
2. Добавить unit-регрессии и HTTP-проверки для `8…`, `+7…` и фрагмента.
3. Запустить unit, typecheck и lint; integration оставить владельцу из-за общей тестовой БД/Redis.

## Результат

Телефонный поиск учитывает ведущую `8` как эквивалент ведущей `7`, сохраняя исходный фильтр, поиск по `+7` и подстроке; ранжирование также получает нормализованные цифры. Добавлены unit- и integration-регрессии. Общий integration-набор прошёл (28/28).
