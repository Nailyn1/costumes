# T-038 · Остальные выборки визитов без фильтра soft delete

- **Приоритет:** medium
- **Область:** Баги домена
- **Создана:** 2026-10-17
- **Выполнена:** 2026-10-18

## Контекст

При работе над T-037 найдены другие выборки в `apps/backend/src/visit-order/visit-order.sevice.ts`, которые не фильтруют `deletedAt: null`: `visitReserved`, `visitForIssue`, `visitUnreturnedDeposits`, `visitIssued`. Списки и карточка могут показывать удалённый визит. Нужно отдельно проверить вложенные выборки заказов в этих методах и добавить тесты.

## Критерии готовности

- [x] Перечисленные выборки не возвращают удалённые визиты.
- [x] Вложенные списки заказов соблюдают soft delete.
- [x] Добавлены unit-тесты.

## План

- Добавить регрессионные unit-тесты на `where` визитов и вложенных заказов в четырёх выборках.
- Добавить `deletedAt: null` к фильтрам визитов и заказов.
- Запустить unit-тесты, typecheck и lint; integration-тесты запускаются владельцем последовательно.

## Результат

- Исправлены `visitReserved`, `visitForIssue`, `visitUnreturnedDeposits`, `visitIssued`; добавлены проверки условий запросов для каждого метода.
- Приёмка: backend unit — 172 passed; integration — 7 passed; typecheck и lint — успешно. Команды запускались напрямую из локальных `node_modules`: `rtk.exe` и `pnpm` в окружении агентов блокировались правами доступа.
- Дополнительные выборки вне рамок этой задачи зафиксированы в T-077.
- Коммит: текущий коммит задачи T-038.
