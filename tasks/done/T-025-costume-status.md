## Контекст

Владелец решил удалить хранимую колонку `Costume.status`: она не обновляется, а занятость и статус в ответе API уже вычисляются по заказам. В восстановленной локальной БД все 519 костюмов имеют `available`, хотя есть 5 выданных заказов. Физическое состояние брони определяется заказами, не этой колонкой.
