## Контекст

Полный `vitest run` периодически падает на разных длинных сценариях UI по стандартному лимиту 5 секунд: `CreateBookingPage.test.tsx`, `ClientsPage.test.tsx`, `IssuePage.test.tsx`. ## Критерии готовности

- [x] Для frontend-набора установлен лимит 15 секунд; assertions и поведение тестов не ослаблены.
- [x] Стандартный `vitest run` проходит без дополнительных флагов.
- [x] Typecheck и lint frontend проходят.

## План

1. Установить лимит для всего frontend-набора в `vitest.config.ts` и убрать временные локальные лимиты из тестов формы брони.
2. Дважды прогнать весь frontend-набор обычной командой, проверить typecheck и lint.
