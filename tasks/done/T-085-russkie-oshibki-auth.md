# T-085 · Русские сообщения ошибок аутентификации

- **Приоритет:** low
- **Область:** Баги домена
- **Создана:** 2026-10-18
- **Выполнена:** 2026-10-18

## Контекст

В `AuthService.refreshTokens`, `JwtRefreshStrategy` и `WsJwtGuard` сообщения об ошибках на английском (`Invalid or expired refresh token`, `User no longer exists`, `Unauthorized: No token provided` и др.). Правило проекта требует русские ошибки для сотрудников. Найдено при покрытии auth тестами (T-045).

## Критерии готовности

- [x] Сообщения 401 для отсутствующего, неверного, истёкшего и отозванного refresh-токена на русском, без раскрытия лишних деталей.
- [x] WS-гард возвращает русские сообщения при отсутствии и неверном токене.
- [x] Unit и integration тесты проверяют новый текст; статус и cookie-поведение остаются прежними.

## План

1. Заменить англоязычные 401-сообщения в auth service, refresh strategy и WS guard на единые русские формулировки без раскрытия деталей токена.
2. Обновить unit и integration тесты сообщений, сохранив статусы и cookie-поведение.
3. Запустить backend unit, integration, typecheck и lint; integration выполнять последовательно с другими агентами из-за общей тестовой БД.

## Результат

Refresh-гард возвращает одно сообщение «Недействительный токен обновления» для ошибок Passport, отозванного токена и удалённого пользователя. Сообщения WS-гарда переведены на русский. Полный backend unit-набор: 261 passed / 6 todo; backend typecheck и lint изменённых файлов прошли. Integration проверяет статус, текст и отсутствие новой cookie при 401; общий последовательный прогон прошёл: 7 наборов, 33 теста.
