## Контекст

`@WebSocketGateway({ cors: true })` разрешал подключение с любого origin; HTTP CORS в `main.ts` ограничен списком.

## Критерии готовности

- [x] Gateway использует тот же список origin, что и HTTP CORS; список в одном месте (`src/config/cors.config.ts`)
- [x] Тест: разрешённый origin получает `Access-Control-Allow-Origin`, чужой — нет (реальные опции из декоратора gateway)

## Результат

`getAllowedOrigins()` (`CLIENT_URL` + localhost-варианты) используется в `main.ts`; gateway получает `cors: { origin: socketCorsOrigin }` — функция, читающая список лениво, потому что декоратор вычисляется при импорте, раньше загрузки `.env` ConfigModule. Токен авторизации сокета (JWT) не менялся. **Владельцу:** на сервере `CLIENT_URL` должен точно совпадать с origin фронтенда (схема+хост+порт, без `/` в конце), иначе веб-сокет перестанет подключаться (HTTP CORS работает по тому же правилу).
