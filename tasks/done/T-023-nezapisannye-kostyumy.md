# T-023 · Незаписанные костюмы

- **Приоритет:** high — до сезона обязательно
- **Область:** Баги домена (подтверждены владельцем, см. domain.md §6)
- **Создана:** 2026-10-15
- **Выполнена:** 2026-10-15

## Контекст

не показывать заказы `returned` и визиты `completed`.

## Критерии готовности

- [x] В списке только заказы с `tagStatus = not_written`.
- [x] Исключены заказы `cancelled` и `returned`.
- [x] Исключены заказы визитов `completed` и `cancelled`.
- [x] Исключены записи с `deletedAt` (заказ и визит).
- [x] Unit-тест на условие выборки.

## Результат

`findOrdersNotWritten` (`apps/backend/src/visit-order/visit-order.sevice.ts`): `where` теперь `tagStatus = not_written`, `deletedAt = null`, `status notIn [cancelled, returned]` и `visit: { deletedAt = null, status notIn [completed, cancelled] }`. Заказы `issued` (костюм уже выдан, бирка не написана) по-прежнему в списке — это соответствует формулировке задачи. Проверено по HTTP: после возврата визита и отмены другого в списке остаётся только заказ активной брони. Из `domain.md` §6 убран пункт про незаписанные костюмы; в §4.2 формулировка «по замыслу» приведена к фактическому поведению.
