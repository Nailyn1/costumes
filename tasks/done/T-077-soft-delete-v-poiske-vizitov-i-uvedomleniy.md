# T-077 · Soft delete в оставшихся выборках визитов и уведомлений

- **Приоритет:** medium
- **Область:** Баги домена
- **Создана:** 2026-10-18
- **Выполнена:** 2026-10-18

## Контекст

При проверке T-038 найдены выборки в `apps/backend/src/visit-order/visit-order.sevice.ts`, не охваченные её четырьмя методами. `visitsIssuedForReturn` выбирает визиты без `deletedAt: null` и включает удалённые заказы; `visitSearch` фильтрует удалённые визиты, но включает удалённые заказы в ответ. В выборках уведомлений также есть `include` визита с заказами без фильтра. Нужен аудит остальных читающих методов этого сервиса, чтобы удалённые записи не попадали в поиск, списки и тексты сообщений.

## Критерии готовности

- [x] Удалённые визиты и заказы не попадают в ответы.
- [x] Добавлены регрессионные тесты для найденных случаев.

- [x] Добавить фильтры soft delete для визитов и вложенных заказов в найденных выборках.
