- [ ] `search-available`: учитывает даты визита — костюм с пересекающимся не отменённым заказом помечается занятым, встык — свободен; отменённые/удалённые заказы не блокируют; возвращённые блокируют (T-024, `it.todo`).

- [x] `list`: пагинация, сортировка, исключение удалённых.
- [x] Тест фиксирует, что занятость считается по заказам, а не по `Costume.status` (domain.md §6.1; T-025).
- [x] Тесты и integration зелёные, typecheck и lint без новых ошибок (запущены напрямую из локальных `node_modules`).
