## Критерии готовности

- [ ] Единый поиск: ввод < 2 символов не ходит в API; debounce; код / имя / костюм / `C-0128` / телефон — запрос уходит с `q`; пустая выдача.
- [ ] Выдача: доплата по умолчанию = остаток (можно 0), тип залога `cash` требует сумму, `document`/`none` — нет; кнопка «Выдать костюмы» блокируется на время мутации (нет двойной отправки), toast «Костюмы выданы. Визит NNNN»; ошибка бэкенда не закрывает модалку.
- [ ] Возврат: «Костюмы возвращены» активна только когда отмечены **все** костюмы; до нажатия ничего не уходит в API; payload `complete-return` (`depositReturned`, `notes`); чекбокс «Залог отдали».
- [ ] Блок «залог не возвращён» (completed, `deposit.returned=false`, `type≠none`): клик → «Забрали ли залог?» → `mark-deposit-returned`.
- [ ] Списки «К выдаче» / «К возврату» обновляются после мутации (инвалидация `["visits"]`).
- [ ] Таблица ↔ карточки на мобильном не тестируем (вёрстка).
- [ ] `pnpm test` зелёные, typecheck и lint без новых ошибок.
