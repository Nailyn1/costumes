## Критерии готовности

- [ ] Список и поиск клиентов (минимум 2 символа, debounce, пустой результат), бейдж «В ЧС» в карточке (`clientResultCard`).
- [ ] Добавление в ЧС: причина (обязательна ли — уточнить у владельца), вызов `POST /clients/:id/blacklist`, UI обновляется; снятие — `DELETE`; ошибка 404.
- [ ] Клиент из ЧС недоступен в форме брони (поиск; есть образец) и в `ClientSelector`; после снятия — доступен.
- [ ] Редактирование клиента/ребёнка: валидация имени и телефона, отправка изменённых данных, обновление кэша.
- [ ] Удаление через `ConfirmDeleteModal` (soft): подтверждение обязательно, отмена ничего не отправляет.
- [ ] Хуки: ключи кэша (`clientKeys`), инвалидация после create/update/delete/blacklist.
- [ ] `pnpm test` зелёные, typecheck и lint без новых ошибок.
