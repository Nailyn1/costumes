# T-080 · Запретить добавление ребёнка удалённому клиенту

- **Приоритет:** medium
- **Область:** Баги домена
- **Создана:** 2026-10-18

## Контекст

`ClientChildService.createChild` проверяет клиента по `id` через `findUnique` без `deletedAt: null`. После мягкого удаления клиента API всё ещё может создать ему ребёнка. См. `apps/backend/src/client-child/client-child.service.ts` и правило soft delete в `.agents/domain.md`.

## Критерии готовности

- [ ] Создание ребёнка у удалённого клиента возвращает 404, запись ребёнка не появляется.
- [ ] Создание ребёнка у активного клиента продолжает работать.
- [ ] Добавлены unit- и интеграционный тесты.
