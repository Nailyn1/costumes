# T-050 · Стандартное время выдачи и возврата по дням недели

- **Приоритет:** medium
- **Область:** Фичи
- **Создана:** 2026-10-17

## Контекст

Владелец хочет настраивать в профиле сотрудника стандартный интервал выдачи и время возврата для каждого дня недели. Настройки профиля можно изменить в любое время. При создании брони время подставляется по выбранным датам; в конкретной брони сотрудник может поправить подставленное время вручную. Реализация отложена.

Стратегия, структура и образцы — [testing.md](../../.agents/testing.md). Бизнес-правила — [domain.md](../../.agents/domain.md). Баги из domain.md §6 не чиним: поведение, которое владелец признал багом, фиксируем `it.todo` со ссылкой на задачу (T-024…T-029).

## Критерии готовности

- [ ] В профиле сотрудника можно задать и позже изменить стандартное время выдачи «с»/«до» и возврата «до» отдельно для каждого дня недели.
- [ ] При выборе дат в форме бронирования время выдачи подставляется по дню выдачи, время возврата — по дню возврата; в самой брони оба значения можно поменять вручную.
- [ ] Логика подстановки покрыта unit-тестами; проходят проверки из Definition of Done.

## План

Отложено по пожеланию владельца. При реализации согласовать начальные значения профиля для уже существующих сотрудников и поведение формы при повторной смене дат после ручной правки времени.
