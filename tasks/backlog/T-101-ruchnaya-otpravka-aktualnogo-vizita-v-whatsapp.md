# T-101 · Ручная отправка актуальных данных визита в WhatsApp

- **Приоритет:** отложено владельцем
- **Область:** Фичи
- **Создана:** 2026-10-22

## Контекст

Владелец просит оставить кнопку отправки на потом, отдельно от быстрой выдачи T-036, редактора T-033 и дополнительной выдачи T-096. При изменении визита автоматических сообщений нет. Уже отправленное сообщение остаётся прежним, а ID и код визита сохраняются.

## Предлагаемый объём для будущего согласования

- Явное действие сотрудника в карточке визита для отправки актуальных данных через существующую очередь WhatsApp.
- Превью текста и адресата; новый факт отправки не переписывает старое сообщение и его историю.
- Согласовать доступные статусы визита, повторную отправку, pending/retry, защиту от дублей и обработку изменённого номера. Использовать политику T-100.
- Тесты без реальных Green-API вызовов, проверка отсутствия отправки из edit/quick/add-and-issue.

## Результат

Записано по просьбе владельца. Не входит в ближайшие реализации; перед началом отдельно утвердить план. Наличие задачи не включает кнопку и не разрешает автоматическую отправку.
