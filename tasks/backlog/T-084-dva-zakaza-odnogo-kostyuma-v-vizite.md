# T-084 · Запретить два заказа одного костюма в одном визите

- **Приоритет:** high
- **Область:** Баги домена
- **Создана:** 2026-10-18

## Контекст

`VisitOrderService.createVisit` передаёт все `costumeId` в `isSuitAvailability`, который ищет только уже сохранённые заказы. Если в одном новом запросе два заказа на один костюм, проверка не находит конфликта между ними и может создать оба. Это нарушает правило одного физического костюма на пересекающийся период (`.agents/domain.md` §3).

## Критерии готовности

- [ ] `POST /visits` отклоняет два заказа одного костюма в одном запросе понятной русской ошибкой 400 до записи визита.
- [ ] Корректные заказы на разные костюмы в одном визите проходят.
- [ ] Unit и integration тесты доказывают отсутствие частично созданного визита при ошибке.
