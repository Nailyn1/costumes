# T-083 · Возврат залога только после завершения визита

- **Приоритет:** medium
- **Область:** Баги домена
- **Создана:** 2026-10-18

## Контекст

`VisitOrderService.MarkDepositReturned` проверяет лишь наличие Deposit. Сейчас endpoint может отметить залог возвращённым, когда визит ещё `reserved`/`issued` или когда тип залога `none`. По флоу возврата (`.agents/domain.md` §4.4) отдельная отметка доступна для завершённых визитов с реальным залогом. Повторный запрос сейчас идемпотентен; его поведение эта задача не меняет.

## Критерии готовности

- [ ] `POST /visits/:id/mark-deposit-returned` принимает только `completed` визит с залогом `cash`/`document`.
- [ ] Для других статусов и типа `none` возвращается понятная русская ошибка 400; несуществующий визит — 404.
- [ ] Повторная отметка остаётся идемпотентной.
- [ ] Unit и integration тесты покрывают допустимый и недопустимые сценарии; остальные сценарии возврата проходят.
