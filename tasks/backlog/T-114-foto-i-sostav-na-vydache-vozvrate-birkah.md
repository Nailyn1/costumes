# T-114 · Фото и состав на выдаче, возврате и бирках (frontend)

- **Приоритет:** high
- **Область:** Фичи
- **Создана:** 2026-10-25
- **Эпик:** [T-032](./T-032-kategorii-i-foto-kostyumov.md)
- **Зависит от:** [T-110](./T-110-sostav-kostyuma-i-snimok-pri-vydache.md), [T-112](./T-112-kamera-i-galereya-foto.md)

## Контекст

Решения владельца: на выдаче фото видно сразу, состав — только подсказка без чекбоксов; на возврате все части отмечены по умолчанию, снятая галочка → запись «Вернули без: …» в истории визита, возврат не блокируется; на бирках фото — по запросу.

## Что сделать

1. **Выдача** — `IssueOrderCard` (`features/visits/components/issuePage/IssueDetails.tsx`, общий для обычной выдачи, модалки быстрой выдачи и «Добавить и выдать»):
   ```
   Алия — Кавказский (Д, 104–116)  C-0412        20 000 ₸
   [▢][▢][▢] →                     ← CostumePhotoStrip, тап → просмотр
   Положить в пакет: Головной убор · Фартук · Саукеле
   ```
   Нет фото → компактная кнопка «📷 Добавить фото» (камера из T-112), без блокировки выдачи. Нет состава → строки нет.
2. **Возврат** — `ReturnFormContent`: под каждым костюмом части из снимка `issuedParts`, **все отмечены**; снятая часть подсвечивается «⚠ Не хватает: Саукеле»; отметка «Костюм возвращён» и кнопка «Костюмы возвращены» работают как сейчас (снятые части их не блокируют); при завершении отправляется `missingParts`. Превью-обложка рядом с костюмом.
3. **История визита** (`VisitHistory`) и карточка визита — отображение события «Вернули без: …».
4. **Незаписанные бирки** (`unrecordedCostumes/*`): кнопка «📷» в строке/карточке — открывает просмотрщик, фото загружаются только по нажатию; при отсутствии фото — «Фото нет» (+ возможность снять).
5. Мобильная версия обязательна (375 px).

## Критерии готовности

- [ ] Выдача (все три сценария) показывает фото и «Положить в пакет»; возврат — отмеченный по умолчанию состав и отправку `missingParts`; бирки — фото по запросу.
- [ ] Событие «Вернули без» видно в истории визита.
- [ ] Vitest: возврат (по умолчанию всё отмечено, снятая часть уходит в запрос, кнопка не блокируется), выдача (подсказка состава, пустые состояния), бирки (фото грузятся только по клику).
- [ ] Сквозной сценарий эпика проверен на телефоне.
- [ ] `.agents/domain.md` §4.2–§4.4 обновлены.
