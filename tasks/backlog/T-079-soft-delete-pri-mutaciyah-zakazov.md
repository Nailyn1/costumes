# T-079 · Soft delete при изменении заказов визита

- **Приоритет:** medium
- **Область:** Баги домена
- **Создана:** 2026-10-18

## Контекст

При аудите T-077 найдены мутации в `apps/backend/src/visit-order/visit-order.sevice.ts`, которые читают или обновляют заказы визита без фильтра `deletedAt: null`: `visitIssue`, `visitUnissue`, `visitCompleteReturn`, `visitCancel`. `orderMarkTagWritten` обновляет заказ по ID без проверки soft delete. Эти методы не входили в T-077, посвящённую читающим выборкам.

## Критерии готовности

- [ ] Перечисленные мутации не читают и не изменяют удалённые заказы.
- [ ] Отметка бирки удалённого заказа возвращает 404.
- [ ] Добавлены регрессионные unit-тесты; интеграционный сценарий добавлен, если меняется сквозной флоу.
- [ ] `pnpm test` и `pnpm test:int` зелёные, typecheck и lint без новых ошибок.
