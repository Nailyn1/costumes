# T-085 · Русские сообщения ошибок аутентификации

- **Приоритет:** low
- **Область:** Баги домена
- **Создана:** 2026-10-18

## Контекст

В `AuthService.refreshTokens`, `JwtRefreshStrategy` и `WsJwtGuard` сообщения об ошибках на английском (`Invalid or expired refresh token`, `User no longer exists`, `Unauthorized: No token provided` и др.). Правило проекта требует русские ошибки для сотрудников. Найдено при покрытии auth тестами (T-045).

## Критерии готовности

- [ ] Сообщения 401 для отсутствующего, неверного, истёкшего и отозванного refresh-токена на русском, без раскрытия лишних деталей.
- [ ] WS-гард возвращает русские сообщения при отсутствии и неверном токене.
- [ ] Unit и integration тесты проверяют новый текст; статус и cookie-поведение остаются прежними.
