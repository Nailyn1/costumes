# Задачи

Учёт работ по проекту. **Одна задача = один файл**, статус задачи = папка, в которой лежит файл.

```
tasks/
├── backlog/       # отложено: всё, что предстоит сделать
├── in-progress/   # выполняется сейчас
└── done/          # сделано
```

## Правила

- **Новая задача** → файл `backlog/T-NNN-short-slug.md` по шаблону ниже. `NNN` — следующий свободный номер среди всех трёх папок (номера не переиспользуются).
- **Взять в работу** → владелец переносит файл в `in-progress/` (`git mv`). Агент сам задачи в работу не берёт и приоритеты не меняет.
- **Сделано** → файл переносится в `done/`, проставляется `Выполнена: YYYY-MM-DD`, отмечаются критерии готовности, в разделе «Результат» — коротко что сделано и коммит/PR.
- **Отказались от задачи** → в `done/` с пометкой `Статус: отменена` и причиной.
- Агент **может создавать** задачи в `backlog/` (найденные баги, техдолг) — вместо того чтобы молча чинить их вне своей задачи.
- Перед стартом задачи в `in-progress/` дописываются критерии готовности и план, если их не было.

Приоритеты: **high** — до сезона обязательно · **medium** — желательно до сезона · **low** — потом.

## Шаблон

```markdown
# T-NNN · Короткий заголовок

- **Приоритет:** high | medium | low
- **Область:** Инфраструктура | CI/CD | Зависимости | Баги домена | Безопасность | Фичи
- **Создана:** YYYY-MM-DD
- **Выполнена:** YYYY-MM-DD   <!-- только в done/ -->
```
